# Booked - E-Commerce Web Application

A student-to-student textbook marketplace exchange platform built for a university project.

## Overview

Booked is a full-stack C2C e-commerce web application developed using PHP and MYSQL. The system allows users to browse products, create accounts, and interact with a database-driven platform, while providing admin functionality for managing content.

## Features

- User registration and login (authentication system)
- Product Browsing and dynamic content display
- Database-drive functionality (CRUD operations)
- Admin RBAC dashboard to manage users, listings, and reports
- Session handling and form processing

## Tech Stack

- PHP
- MYSQL
- HTML/CSS
- Localhost environment
